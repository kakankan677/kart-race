# Kart Rush

iPhone の Safari で遊べる 3D カートレース。HTML 1 ファイル（`index.html`）だけで動き、Claude Code で作った。

- AI カート 3 台と 3 周勝負
- コーナーでドリフトを溜めて、離した瞬間にブースト（長く溜めるとスーパーブースト）
- 傾け操作・タッチ操作・キーボード操作に対応
- 効果音は WebAudio で合成（音声ファイルなし）、3D は Three.js

## 遊び方

アクセルは自動。コース外（縁石の外）に出ると減速し、生け垣より外には出られない。

| 操作 | 傾け | タッチ | キーボード |
|---|---|---|---|
| ハンドル | iPhone を横に持ち、ハンドルのように傾ける | 画面の左半分 / 右半分を押す（端ほど強く曲がる） | ← → / A D |
| ドリフト | 画面のどこかを押し続ける（右下ボタンでも可） | 右下の DRIFT ボタンを押し続ける | Space / Shift |
| ブレーキ | なし | なし | ↓ / S |

ドリフトはある程度の速度でハンドルを切りながら始まる。ボタンがオレンジ→水色に変わったらブーストが溜まった合図。

## iPhone で遊ぶ

1. 公開 URL を Safari で開く（下の「公開」を参照）。
2. 「傾けて操作」を押すと、iOS が「動作と方向へのアクセス」を確認するので許可する。
3. 共有ボタン →「ホーム画面に追加」で、全画面のアプリとして起動できる。

傾きの向きが逆に感じたら、タイトル画面の「傾きの向きを反転する」をオンにする（この設定は端末に保存される）。

別の置き場所（GitHub Pages など静的ホスティング）でも `index.html` をそのまま置けば動く。https であることが条件（傾きセンサーの許可に必要）。

## 設計メモ

- **1 ファイル・ビルドなし**: Node や Xcode を入れずに作れて、どこにでも置ける。外部依存は cdnjs の Three.js 0.160.0（UMD ビルド）だけ。
- **Artifact で配布**: Apple Developer Program（有料）や 7 日ごとの再署名なしで、URL だけで他人の iPhone に届く。代わりに、Artifact の iframe ではセンサー類が使えない可能性があり、その場合はタッチ操作に自動で切り替える。
- **コース**: 12 個の制御点を Catmull-Rom スプラインでつないだ閉ループを 600 点に等間隔サンプリングし、点の添字をそのまま進行度にしている。最小カーブ半径は約 8.4（道幅 8）で、ヘアピンはドリフトしないと曲がりきれない。
- **物理はアーケード**: 速度は目標値へ指数的に近づける。ドリフト中は曲がる方向を固定し、ハンドルで強弱だけ変える。コース外は目標速度を半分にする。
- **AI**: スプラインの先の点へ向かう単純な追従。先の道の曲がり具合で速度を落とし、プレイヤーとの差に応じて少し速く・遅くする（接戦になるように）。
- **デバッグ**: ブラウザのコンソールで `KR.dbg.auto = true` にすると AI がプレイヤーを運転する。`KR.state`・`KR.karts` で状態を読める。

## 既知の制約

- iOS Safari は振動（バイブ）に対応していない。
- 音は最初のタップ（ボタン押下）の後から鳴る（iOS の仕様）。
- アイテムとミニマップはない。基本版が安定してから追加候補にする。
